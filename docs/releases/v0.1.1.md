# Text Time Roll v0.1.1

## 中文

- **34 种缓动**：常用曲线系列的缓入/缓出/缓入缓出，以及阶梯、保持。
- **真实上下逐位滚动**：出入字形同时过渡并裁切；支持同步、左→右、右→左启动及0–80%错峰。
- **恢复经典单列界面**：保留完整参数名称、按钮和说明，新选项沿用旧版布局。
- **兼容v0.1.0场景**：旧数值/格式/时间和原三个缓动ID不变；仅启用滚动时增加辅助层。
- **保护原出场动画**：修复变形器数组自动重排造成重复连接的风险，重复应用/恢复保留原连接顺序和作用层级。
- Windows/macOS共用单一UI Script。macOS Cavalry2.7.2真实验证；跨平台自动化覆盖见仓库Actions及docs/TESTING.md。Windows Cavalry真机验证仍待补充。

**安装：** 解压ZIP，将 `Text Time Roll.js` 放进 Cavalry **Scripts → Show Scripts Folder** 打开的目录；关闭旧面板，再从Scripts菜单打开。先读取旧参数，再应用并保存工程。

**模式说明：** 上下滚动为各位独立动画，中间显示不保证按年份数值递增；想要连续数值插值请选择“仅数值递增/递减”。Back/Elastic会超调，Bounce可能回摆。完整说明见README与教程。

## English

- **34 easings:** common In/Out/In-Out families, steps and hold.
- **Real up/down digit wheels:** clipped outgoing/incoming glyphs; together/LTR/RTL start order with0–80% stagger.
- **Classic single-column UI:** full labels, buttons and instructions, with new controls in the familiar layout.
- **v0.1.0 migration:** preserves previous numeric/format/timing parameters and easing IDs. Rolling helpers are added only when enabled.
- **Entrance preservation:** handles Cavalry's shrinking/reindexing deformer arrays safely; Apply/Restore retains original stack order and level mode.
- One Windows/macOS UI Script. Real-app checks on macOS Cavalry2.7.2; see Actions and docs/TESTING.md for automated coverage. Windows Cavalry itself remains unverified.

**Install:** Extract the ZIP, copy `Text Time Roll.js` into **Scripts → Show Scripts Folder**, close the old panel and reopen from Scripts. Read existing parameters, Apply and save the Scene.

**Modes:** Independent digit wheels do not guarantee chronological intermediate numbers. Use number-only mode for numeric interpolation. Back/Elastic can overshoot and Bounce can reverse. See README/tutorial for full details.
