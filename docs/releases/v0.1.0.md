# Text Time Roll v0.1.0

## 中文

首版 **Cavalry 文本年份/数值递增插件**，Windows 与 macOS 使用相同的 `Text Time Roll.js`。

- 1978 → 2026 等数值递增/递减；不是机械式上下数字滚轮。
- 中文/English 面板，帧/秒、三种缓动、补零、小数与前后缀。
- 只接管指定文本层的文字输入，保留原控制器，可恢复、可重复更新。
- 场景内自包含表达式，关闭插件面板后继续求值；无网络/遥测/密钥。
- 双语 README、使用教程、测试说明及 SHA-256 校验文件。

**安装：** 下载 ZIP 并解压，将 `Text Time Roll.js` 放入 Cavalry **Scripts → Show Scripts Folder** 打开的目录，再通过 Scripts 菜单打开。

**验证范围：** macOS Cavalry 2.7.2 实测；跨平台逻辑/UI 模拟与打包测试。Windows Cavalry 真机测试待补充，不保证所有环境无 bug。开发时私有场景重载脚本曾导致宿主意外退出，详细边界在 `docs/TESTING.md`；正式插件无场景重载代码。

## English

Initial **Cavalry numeric/year counter**, with the same `Text Time Roll.js` on Windows and macOS.

- Increasing/decreasing values such as 1978 → 2026; not mechanical vertical digit wheels.
- Chinese/English UI, frames/seconds, three easings, zero-padding, decimals and affixes.
- Take over one text input while retaining its original controller; restore and update in place.
- Self-contained scene expression works without the panel; no networking, telemetry or keys.
- Bilingual README/tutorial, test notes and SHA-256 checksums.

**Install:** Extract the ZIP, put `Text Time Roll.js` in **Scripts → Show Scripts Folder**, then open it from Scripts.

**Validation:** real-app checks on macOS Cavalry 2.7.2 plus cross-platform logic/UI mocks and packaging tests. Windows Cavalry itself remains unverified. A private developer scene-reload harness was followed by a host exit; see `docs/TESTING.md`. The distributed plugin contains no scene-reload code. No universal bug-free guarantee.
